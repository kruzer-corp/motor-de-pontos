# Motor de Pontos

Painel de administração para o Motor de Pontos — programa de fidelidade de pontos.

## Stack

- React 19 + TypeScript
- Vite (build tool)
- Tailwind CSS 4
- @kruzer-corp/ds (design system)
- React Router (navegação)

## Como rodar localmente

```bash
npm install
npm run dev
```

Abre em `http://localhost:5173/` por padrão.

## Build

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
